🎨 Colour Palette and Contrast

📌 Project Overview

This project focuses on creating a clean and consistent UI design system by applying fundamental visual design principles.

It demonstrates how colour palettes, contrast, typography and spacing work together to create attractive, readable and user-friendly interfaces.

🎯 Project Objectives

- Understand primary, secondary and neutral colours.
- Learn the importance of colour contrast and readability.
- Establish a clear visual hierarchy.
- Apply an 8-point spacing grid.
- Create a consistent typography scale.
- Design a sample dashboard interface using the selected design system.
